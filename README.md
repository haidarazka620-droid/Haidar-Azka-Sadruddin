# Haidar-Azka-Sadruddin
**Monster Quiz** adalah game web edukasi RPG untuk siswa SMP (kelas 7–9). Pemain melawan gelombang monster dan bos dengan menjawab soal pilihan ganda IPA, IPS, dan Matematika berbatas waktu. Kumpulkan emas, naik level, gunakan *skill*, dan koleksi beragam senjata langka untuk mengalahkan semua musuh!
